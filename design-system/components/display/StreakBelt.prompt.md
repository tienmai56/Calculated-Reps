Friendship streak visual — one segment per calendar week, joined like a belt. Use on Friends rows, profiles, and the post-publish celebration.

```jsx
<StreakBelt hue="sky" weeks={[false,true,true,true,true,true,true,true]} thisWeek="pending" />
<StreakBelt hue="plum" weeks={[true,true,true,false,false]} thisWeek="pending" />  {/* broken */}
```
- Pair the belt with copy like "8 weeks with Sarah" — never ranks, never guilt.
